# Land a useful SIMBA lifecycle

Make SIMBA select and retain a natural reflective mutation that is useful on a realistic task, rather than relying only on genuine-but-rejected mutations.

## Acceptance Criteria

A natural public SIMBA run uses disjoint training/selection/test data, selects a non-baseline mutation with positive untouched utility, retains the Artifact/report/budget, and executes error-free after fresh trusted reload.
