# Preliminary Finalist Screen

## Conclusion

The intrinsic master-brand ranking is unchanged. This screen adds factual
namespace and public-market observations to the top 20; it does not convert
them into a single score or silently eliminate candidates.

The most important observations are directness-sensitive:

- `Enact` has an active, direct same-category use as a generative-software
  framework.
- `DSX`, `Attune`, `Praxon`, and `Recurra` have active AI or developer-tool
  uses close enough to require serious comparison.
- `Trellis` is the only top-20 candidate with an observed exact Hex package.
- `Metraxis` has the cleanest lightweight namespace result, but remains rank 19
  because namespace cleanliness does not repair semantic opacity.

These are screening flags, not trademark conclusions. Exact intended use,
jurisdiction, active marks, common-law use, listener behavior, and identity
architecture remain unresolved.

## Weighting Policy

1. Owner taste, project truth, identity architecture, and durability determine
   intrinsic rank.
2. Active direct same-category use and the intended Hex namespace are material
   screening evidence.
3. Adjacent package records, GitHub counts, domains, and distant-industry uses
   are context, not automatic vetoes.
4. Listener, accessibility, international, cultural, and legal review remain
   separate human or qualified gates.
