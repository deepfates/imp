# Corrective Form-Saturation Brief

This brief governs the independent `form-saturation-c` and
`form-saturation-d` waves. It supplements the complete matrix and falsifiable
tests in `identity/reports/saturation-form-audit.md`; that audit remains the
authority when this brief is silent.

The purpose is to test lexical and identity mechanisms that the earlier waves
under-delivered. This is raw divergence, not selection. Preserve every result,
including hostile, malformed, overlapping, culturally unsafe, and deliberately
non-code observations. Do not rank, shortlist, availability-check, or repair a
surface after seeing the corpus.

## Isolation

1. Read the product boundary, atlas, portfolio schema, this brief, and only the
   assigned matrix cells before ideation.
2. Do not read existing candidate surfaces, registries, enrichments, scores, or
   the other corrective wave while generating and freezing surfaces.
3. After surfaces are frozen, mechanically compare normalized candidate IDs
   with the accepted registry. Record each accidental match in a note; never
   replace the surface to hide an overlap.
4. Each portfolio records its actual agent or model, method, prompt path and
   SHA-256, and has no parent run unless a real lineage exists.

## Truth And Structure

- Use only current atlas IDs and schema keys. Keep ordinals contiguous.
- Each ten-observation cell has exactly two wildcards and includes affirmative,
  ambivalent, and adverse forms.
- Every observation has a pronunciation, grammar, etymology or explicit
  `coined/no source` statement, candidate-specific rationale, audience lenses,
  architecture lenses, concerns, scope, and mechanism notes.
- A current embodiment may name only behavior verified in the repository. Do
  not claim durable rollback, haptics, councils, redress institutions, public
  governance, carbon accounting, legal guarantees, or user research.
- A horizon embodiment must remain conditional. It may test instructions,
  demonstrations, tool descriptions, retrieval policies, playbooks, schemas,
  code fragments, and configuration, but must not present them as shipped.
- Refusal, repair, accessibility, and power notes must identify a concrete
  actor, action, access path, cost, and unavailable mechanism. Do not reuse a
  generic caller-only route across candidates.

## Mechanism Precision

- A true blend must fuse recoverable source stems by overlap or truncation. A
  spaced or concatenated compound is not a blend. Label the exact operation.
- Sound figures must distinguish alliteration, full or slant rhyme,
  reduplication, consonance, assonance, ideophone, and onomatopoeia. Do not call
  something ideophonic merely because it sounds playful.
- Compact forms must distinguish abbreviation, initialism, pronounceable
  acronym, wordlike acronym, dual reading, and backronym.
- Code projections use conventional lowercase Hex and OTP identifiers, an
  Elixir alias root, Mix task prefix, config prefix, and telemetry prefix.
  Display syntax and runtime aliases are separate surfaces. Give a precise
  non-code reason when no viable projection exists.
- Identity grammars render actual roles: master, category descriptor, Elixir
  library, research effort, community, company or steward, protocol, hosted
  product, and product family. Mark roles unavailable when they would overclaim.
- Source-language forms name the language, meaning, morphology, pronunciation,
  transliteration system where applicable, source, review status, and cultural
  context. Unverified work stays visible but does not claim validated coverage.
- Counter-claims are documentation or governance identities that delimit scope,
  not merely alarming package names.
- Citation forms include a pinned title, author or institution, year when
  available, and URL or DOI, plus an appropriation or stewardship note. Include
  non-eponymic alternatives.

## Post-Generation Checks

Validate the exact portfolio with `DSEx.IdentityCheckpoint`, verify the planned
count and wildcard quota, inspect every record, and report all overlaps and
known shortfalls. A passing JSON schema is necessary but not evidence that the
wave established saturation.
